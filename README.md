## 🚀 Running Locally

You can run this website with any static local web server:

### Using Python:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000/` in your browser.

### Using Node.js / npx:
```bash
npx serve .
```

## 🎨 Sections Overview

1. **Navbar**: Fixed header with circular glasses logo, active yellow pill navigation, and mobile hamburger drawer.
2. **Hero**: Developer introduction, "HIRE ME" smooth-scroll CTA, and vector illustration.
3. **Skills**: Categorized cards for Programming, Frontend, Backend, Database, and Core Tools.
4. **Education**: Clean card for B.Tech in CSE at Galgotias University (3rd Year).
5. **Projects**: 3-column desktop grid with 6 projects, technology tags, and interactive detail modals.
6. **Recommendations**: Interactive slider/carousel with pagination dots and active highlighted state.
7. **Contact**: "Leave ME Your Info" form with real-time validation + contact information cards.
8. **Footer**: Social badges, navigation links, and copyright bar.
